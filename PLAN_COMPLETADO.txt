OBJETIVO
────────
Crear un reporte estático e interactivo de la Actividad 02 (Portafolios Óptimos)
con análisis real ejecutado (Markowitz + Monte Carlo + Comparación) y publicarlo
en Netlify con deploy manual.

CONTENIDO DEL REPORTE
──────────────────────
1. Resumen Ejecutivo
2. Parte 1 — EDA
   - Estadísticas descriptivas (retorno, volatilidad por activo)
   - Distribuciones de retornos (histogramas con plotly)
   - Matriz de correlaciones (heatmap interactivo)
   
3. Parte 2 — Markowitz
   - Cálculo frontera eficiente exacta (50 puntos con quadprog)
   - Portafolio tangente: SPY 52.77% / AGG 47.23%, Sharpe = 1.0214
   - Gráfico interactivo de la frontera (hover con cifras)
   
4. Parte 3 — Simulación
   - 10,000 portafolios aleatorios (set.seed(42))
   - Mejor simulado: SPY 44.97% / AGG 48.05%, Sharpe = 0.9439
   - Nube interactiva coloreada por Sharpe ratio
   
5. Parte 4 — Comparación
   - Overlay: nube simulada + frontera exacta
   - Tabla de brecha (error simulado vs Markowitz)
   - Composición de pesos (diferencias)
   
6. Parte 5 — Calculadora Interactiva
   - Sliders para 5 activos (SPY, EFA, IJS, EEM, AGG)
   - Normalización automática a 100%
   - Cálculo en vivo: retorno, volatilidad, Sharpe
   - Visualización de la posición sobre la frontera

FUNCIONES R (R/portafolio.R)
────────────────────────────

- matriz_correlacion()        : Correlación entre activos
- calcular_frontera_markowitz() : Frontera exacta (quadprog)
- simular_portafolios()       : 10k portafolios aleatorios
- calcular_brecha()           : Compara Markowitz vs simulado
- exportar_pesos_json()       : Genera JSON para OJS

PRÓXIMOS PASOS (Para Deploy a Netlify)
───────────────────────────────────────
1. Instalar netlify-cli:
   npm install -g netlify-cli

2. Autenticarse:
   netlify login

3. Deploy a staging (preview):
   cd netlify_actividad02
   netlify deploy --dir=_site

4. Verificar en navegador (URL de draft)

5. Deploy a producción:
   netlify deploy --dir=_site --prod

6. Actualizar link en CLAUDE.md y actividad_02_portafolios.qmd
   con la URL definitiva (ej: https://portafolios-fen.netlify.app)

7. Final commit:
   git add . && git commit -m "fix: Update Netlify URLs with production domain"
