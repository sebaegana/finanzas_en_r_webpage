🎯 Bienvenida

Este curso integra código real, IA asistida y herramientas modernas (Claude Code, Positron) para enseñar finanzas cuantitativas con R.

Dos enfoques pedagógicos: - 📖 clases/ — Material tradicional (2024-2025): PDFs con explicaciones teóricas - 🤖 clases_ia/ — Material con IA (nuevo): Notebooks interactivos + análisis ejecutado en vivo

📂 Estructura de Carpetas

clases/ — Material Heredado (PDF)

clases/
├── index.qmd              # Listing automático de todas las clases
├── actividad_01.qmd       # Actividad 01 (Limpieza de datos)
├── notebook_01.qmd        # Clase 01 (Notebook teórico)
├── diccionario_terminos.qmd

    ├── chess.csv

Uso: - Materiales congelados (no se ejecutan en Quarto) - Ideal para explicaciones teóricas largas - Contienen pseudocódigo y ejemplos conceptuales

🚀 Cómo Usar Este Repositorio

Opción 1: Ver Online (Recomendado para revisar rápido)

  • Sitio del curso: sebaegana.github.io/finanzas_en_r_webpage/
  • Reporte Actividad 02: portafolios-fen.netlify.app

Opción 2: Descargar y Usar Localmente

Paso 1: Descarga el repo como ZIP

# O descarga desde GitHub:
# https://github.com/sebaegana/finanzas_en_r_webpage/archive/refs/heads/main.zip

unzip finanzas_en_r_webpage-main.zip
cd finanzas_en_r_webpage-main

Paso 2: Instala dependencias

# R packages
Rscript -e "renv::restore()"

# Quarto (si no lo tienes)
https://quarto.org/docs/get-started/

# netlify-cli (para deployar Actividad 02)
npm install -g netlify-cli

Paso 3: Renderiza localmente

# Renderizar un archivo específico
quarto render clases_ia/actividad_02_portafolios.qmd

# Renderizar TODO el sitio
quarto render

# Preview en navegador
quarto preview clases_ia/herramientas.qmd

Paso 4 (Opcional): Deploy a Netlify

cd netlify_actividad02
quarto render --to html
netlify login
netlify deploy --dir=_site --prod

🔧 Archivos de Configuración

_quarto.yml (Raíz)

Configuración global del sitio Quarto: - Define estructura de navegación (navbar) - Tema cosmo - Opciones de ejecución (freeze: auto)

renv.lock

Archivo de bloqueo de dependencias R. Permite reproducibilidad:

renv::restore()  # Instala exactas las versiones

.github/workflows/quarto-render.yml

GitHub Actions: renderiza automáticamente al hacer push a main.

🎓 Flujo de Aprendizaje Recomendado

Semana 1-2: Fundamentos

  1. Leer: clases_ia/herramientas.qmd (setup de herramientas)
  2. Leer: clases_ia/intro.qmd (IA en finanzas)
  3. Hacer: Instalar Claude Code + Positron
  4. Hacer: Fork del repo

Semana 3-4: Primeras Actividades

  1. Leer: clases_ia/notebook_01.qmd (concepto de desarrollo asistido)
  2. Hacer: clases_ia/actividad_01_con_ia.qmd (limpieza de datos)
    • Opción A: Escribes todo manualmente
    • Opción B: Híbrida (mezcla manual + IA)
    • Opción C: IA genera todo, tú interpretas

Semana 5-8: Proyecto Principal

  1. Hacer: clases_ia/actividad_02_portafolios.qmd
    • Análisis Markowitz + Simulación
    • Deploy a Netlify (ver netlify_actividad02/DEPLOY.md)
  2. Hacer: clases_ia/trabajo.qmd (proyecto final)
    • Tema: elige uno de finanzas cuantitativas
    • Entrega: GitHub repo + Netlify URL
