📊 Proyectos Destacados

Actividad 02: Portafolios Óptimos

Análisis completo de optimización de portafolios usando Markowitz + Simulación Monte Carlo:

  • Datos: 108 meses de retornos históricos (SPY, EFA, IJS, EEM, AGG)
  • Análisis: EDA → Frontera eficiente exacta (quadprog) → 10,000 simulaciones aleatorias → Comparación
  • Resultados: Portafolio tangente (Sharpe = 1.0214) vs mejor simulado (Sharpe = 0.9439)
  • Deploy: Reporte estático en Netlify (3.8 MB, carga en <1s)

→ Abrir reporte interactivo en Netlify

🎯 Estructura Recomendada para Usar Este Material

Para Estudiantes:

  1. Descarga el ZIP completo o clona el repositorio
  2. Instala dependencias: Rscript -e "renv::restore()"
  3. Sigue el flujo: Herramientas → Intro → Clases → Actividades → Proyecto
  4. Completa cada actividad usando Claude Code (opcional: modo IA-asistido)
  5. Deploy tu proyecto final a Netlify

Para Profesores:

  1. Descarga e inspecciona la estructura
  2. Revisa RESPUESTAS_PROFESOR.md (soluciones)
  3. Revisa EVALUACIONES_PROFESOR.md (rúbricas)
  4. Personaliza con tus datos/objetivos
  5. Deploy repositorio a GitHub + Netlify

💻 Tecnología del Curso

  • R: Análisis de datos, modelos financieros (quadprog, tidyverse, ggplot2)
  • Quarto: Documentos dinámicos (código + markdown)
  • Claude Code: IDE con IA integrada (async prompting)
  • Positron: IDE científico (alternativa a RStudio)
  • Netlify: Deploy de reportes estáticos (gratuitamente)
  • GitHub: Control de versiones + GitHub Pages
