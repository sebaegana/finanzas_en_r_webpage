Introducción: El Problema

Contexto: Tienes acceso a 5 activos financieros: SPY (S&P 500), EFA (mercados desarrollados), IJS (small-cap), EEM (mercados emergentes), AGG (bonos). Deseas construir un portafolio que maximice el retorno relativo al riesgo, pero no sabes qué pesos asignar a cada uno.

Pregunta central: - ¿Cómo encontrar los pesos óptimos? - ¿Es mejor simular miles de combinaciones (fuerza bruta) o resolver un problema de optimización exacto? - ¿Cómo publicar ese resultado para que otros lo usen?

Tu rol: seguir un pipeline de datos completo: 1. Parte 1 — EDA: entender los datos y correlaciones entre activos 2. Parte 2 — Simulación: aproximar la frontera eficiente generando miles de portafolios aleatorios 3. Parte 3 — Markowitz: resolver exactamente y comparar con la simulación 4. Parte 4 — Servicing: publicar el resultado como una página interactiva en este sitio

En cada parte, verás dos enfoques: Manual (escribes cada línea de código, ~50-60 min total) y Asistido con Claude Code (~10-15 min).

Parte 2 — Modelos: Simulación de Portafolios (Monte Carlo)

Enfoque Manual

Paso 1: Preparar datos y matriz de covarianza

# Descargar o cargar (ya hecho en Parte 1)
portafolio_retornos <- read_csv("data/portafolio_retornos.csv")

# Extraer matriz de retornos
retornos_matrix <- portafolio_retornos %>%
  select(-fecha) %>%
  as.matrix()

# Calcular parámetros
retornos_esperados <- colMeans(retornos_matrix)
cov_matrix <- cov(retornos_matrix)
sd_activos <- apply(retornos_matrix, 2, sd)

Tiempo: ~5 minutos.

Paso 2: Simular miles de portafolios aleatorios

set.seed(42)

# Parámetros de simulación
n_sims <- 10000
n_activos <- ncol(retornos_matrix)
tasa_libre_riesgo <- 0.02 / 12  # tasa anual / 12 meses

# Matriz para guardar resultados
resultados_sim <- matrix(NA, nrow = n_sims, ncol = 4)
colnames(resultados_sim) <- c("retorno", "volatilidad", "sharpe", "mejor_sharpe")

# Matriz para guardar pesos
pesos_optimos <- matrix(NA, nrow = n_sims, ncol = n_activos)

# Simulación
for (i in 1:n_sims) {
  # Generar pesos aleatorios long-only
  w <- runif(n_activos)
  w <- w / sum(w)  # Normalizar a que sumen 1

  # Retorno esperado del portafolio
  ret_port <- sum(w * retornos_esperados)

  # Volatilidad del portafolio
  var_port <- t(w) %*% cov_matrix %*% w
  vol_port <- sqrt(var_port)

  # Sharpe ratio
  sharpe <- (ret_port - tasa_libre_riesgo) / vol_port

  # Guardar resultados
  resultados_sim[i, 1] <- ret_port * 12  # Anualizar
  resultados_sim[i, 2] <- vol_port * sqrt(12)  # Anualizar
  resultados_sim[i, 3] <- sharpe
  pesos_optimos[i, ] <- w
}

# Convertir a data frame
sim_df <- as.data.frame(resultados_sim)
colnames(sim_df) <- c("retorno_anual", "volatilidad_anual", "sharpe_ratio")

# Identificar mejor Sharpe
idx_mejor <- which.max(sim_df$sharpe_ratio)
mejor_sharpe_sim <- sim_df[idx_mejor, ]
mejor_pesos_sim <- pesos_optimos[idx_mejor, ]

cat("Mejor portafolio simulado (máx Sharpe):\n")
print(mejor_sharpe_sim)
cat("\nPesos:\n")
print(setNames(mejor_pesos_sim, colnames(retornos_matrix)))

Tiempo: ~15 minutos (loop, debugging de dimensiones).

Parte 3 — Modelos: Optimización de Markowitz y Comparación

Enfoque Manual

Paso 1: Teoría breve

La frontera eficiente de Markowitz resuelve:

\[\min_w \left[ w^T \Sigma w \right]\]

sujeto a: - \(w^T r = r_p\) (retorno objetivo) - \(\sum w_i = 1\) (pesos suman 1) - \(w_i \geq 0\) (long-only, sin venta corta)

donde \(\Sigma\) es la matriz de covarianza y \(r\) es el vector de retornos esperados.

Paso 2: Instalar y usar quadprog

# Instalar si no está (comentar después)
# install.packages("quadprog")

library(quadprog)

# Parámetros ya calculados en Parte 2
retornos_esperados  # vector de medias
cov_matrix          # matriz de covarianza

# Función para calcular frontera eficiente
calcular_frontera <- function(retornos_esperados, cov_matrix,
                              r_min, r_max, n_puntos = 50) {
  resultados_frontier <- matrix(NA, nrow = n_puntos, ncol = 3)
  colnames(resultados_frontier) <- c("retorno_objetivo", "volatilidad", "pesos")

  retornos_objetivo <- seq(r_min, r_max, length.out = n_puntos)

  for (i in 1:n_puntos) {
    r_obj <- retornos_objetivo[i]

    # Formulación para quadprog: solve.QP(H, f, A, b0)
    # Minimiza: (1/2) * x^T H x + f^T x
    # Sujeto a: A^T x >= b0

    H <- 2 * cov_matrix
    f <- rep(0, length(retornos_esperados))

    # Restricciones:
    # 1) sum(w) = 1  -> w1 + w2 + ... + wn = 1
    # 2) w^T * r = r_obj
    # 3) w_i >= 0

    # Matriz A y vector b0 para restricciones de igualdad (convertidas a desigualdad)
    A <- cbind(
      rep(1, length(retornos_esperados)),      # sum(w) = 1
      retornos_esperados                        # w^T * r = r_obj
    )

    # Esto es complicado en quadprog, usamos solución alternativa...
  }

  return(resultados_frontier)
}

Nota: quadprog es poderosa pero tiene una sintaxis tediosa para restricciones mixtas (igualdad + desigualdad). Con IA, esto se simplifica.

Tiempo: ~20 minutos (frustración, búsqueda en documentación).

Prompt simplificado:

“Optimiza la frontera eficiente de Markowitz usando los datos de portafolio_retornos.csv: - Long-only (pesos entre 0 y 1, suman 1) - Calcula 50 puntos en la frontera barriendo retornos de 8% a 20% anual - Para cada punto, resuelve: minimizar varianza sujeto a retorno objetivo - Resultado: tabla con (retorno, volatilidad, pesos de cada activo) y gráfico overlay con la nube de simulación de la Parte 2 para comparar”

Lo que genera (minutos, no manual):

library(quadprog)

# Función helper: optimizar para un retorno objetivo
optimizar_portafolio <- function(w, cov_matrix, retornos_esperados, r_target) {
  # Usar optimize package
  resultado <- optim(
    par = w,
    fn = function(x) as.numeric(t(x) %*% cov_matrix %*% x),
    method = "SLSQP",
    ui = rbind(-diag(length(x)), diag(length(x)), -retornos_esperados, retornos_esperados),
    ci = c(rep(0, length(x)), rep(-1, length(x)), -r_target, r_target)
  )
  return(resultado$par)
}

# Frontera eficiente
frontera <- expand.grid(
  retorno_objetivo = seq(0.08, 0.20, length.out = 50)
) %>%
  rowwise() %>%
  mutate(
    pesos = list(optimizar_portafolio(...)),
    volatilidad = sqrt(t(pesos) %*% cov_matrix %*% pesos) * sqrt(12)
  )

# Gráfico combinado
ggplot() +
  geom_point(data = sim_df, aes(x = volatilidad_anual, y = retorno_anual,
                                color = "Simulada"), alpha = 0.3) +
  geom_line(data = frontera, aes(x = volatilidad, y = retorno_objetivo * 12,
                                 color = "Markowitz"), size = 1.2, color = "red") +
  theme_minimal()

Parte 4 — Servicing: Publicar como Página Interactiva

Opción C: Minimalista (Prompt-Driven)

Pídele a Claude Code el flujo completo en 1-2 prompts:

“Análisis completo de portafolio: 1. EDA de portafolio_retornos.csv 2. Simular 10,000 portafolios long-only 3. Optimizar Markowitz (frontera eficiente) 4. Gráfico overlay 5. Bloque ojs con sliders interactivos para ajustar pesos Todo en un único .qmd”

Claude Code genera ~600 líneas de código profesional en ~2 minutos. Tu rol: revisar, entender, y interpretar los resultados.

Reflexión Final: IA como Herramienta, No Reemplazo

✅ Usa IA para:

  • ✅ Boilerplate: cargas, librerías, transformaciones estándar (ahorra 60%)
  • ✅ Exploración: “¿cómo haría esto en tidyverse?” vs “¿cómo en data.table?”
  • ✅ Debugging: “¿por qué falla este argumento de quadprog?”
  • ✅ Observable JS: IA domina esta sintaxis mejor que la mayoría de humanos
  • ✅ Documentación: genera comentarios y explicaciones automáticamente

❌ NO uses IA para:

  • ❌ Decisiones financieras: TÚ eliges qué ponderación investigar, IA genera código
  • ❌ Validación: verifica siempre que Sharpe = (retorno - rf) / vol (no confíes ciegamente)
  • ❌ Comprensión: entiende el código antes de publicarlo (“¿qué está haciendo este loop?”)
  • ❌ Pensar: IA acelera la ejecución, no la estrategia analítica

La Mentalidad Correcta

“IA es como un copiloto competente: escribe código, pero TÚ diriges el análisis financiero. Verificas cada resultado, cuestiona las correlaciones, decide pesos en función de tu hipótesis, no al revés.”
