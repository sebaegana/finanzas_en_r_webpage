Fase 7 � Calcular indicadores de rentabilidad

ROE (Return on Equity) y ROA (Return on Assets) son claves para inversores:

# Supuestos simplificados
activos_totales <- 150  # $ millones
patrimonio <- 90        # $ millones (capital + ganancias retenidas)

datos_techcorp <- datos_techcorp %>%
  mutate(
    # Ganancia anualizada (4 trimestres)
    ganancia_anual = ganancia_neta * 4,
    # ROA = ganancia anual / activos
    roa = round(ganancia_anual / activos_totales * 100, 1),
    # ROE = ganancia anual / patrimonio
    roe = round(ganancia_anual / patrimonio * 100, 1)
  )

# El ROE de TechCorp es muy fuerte (>30% es excelente)
tail(datos_techcorp[, c("trimestre", "roe", "roa")], 1)

Estos n�meros indican si la empresa genera valor para accionistas.
